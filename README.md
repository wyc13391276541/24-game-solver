# 24点计算器

一个简单的24点游戏求解器，启动时可选择中文或英文界面。

## 功能

- 输入4个数字（1-13），自动计算所有能得到24的解法
- 自动去重，不显示重复算式
- 启动时选择中英文
- Windows版可直接运行，无需安装Python

## 使用

**Windows用户**：下载 `24点计算器.exe`，双击运行。

**Python用户**：
```bash
python 24-point-calculator.py
```

运行后选语言，然后按提示输入数字即可。

## 示例

```
👉 1 2 3 4
🎉 共找到 1 个不重复解法：
   解法1: (1+3)*(2+4) = 24
```

```
👉 5 5 5 5
🎉 共找到 1 个不重复解法：
   解法1: 5*5-5/5 = 24
```

# 24 Point Calculator

A simple 24-point game solver with language selection on startup (Chinese or English).

## Features

- Enter 4 numbers (1-13), find all expressions that equal 24
- Automatic deduplication
- Choose Chinese or English at launch
- Windows executable available, no Python required

## Usage

**Windows users**: Download `24点计算器.exe` and double-click.

**Python users**:
```bash
python 24-point-calculator.py
```

Select your language at startup, then follow the prompts.

## Example

```
👉 1 2 3 4
🎉 Found 1 unique solution:
   Solution 1: (1+3)*(2+4) = 24
```

```
👉 5 5 5 5
🎉 Found 1 unique solution:
   Solution 1: 5*5-5/5 = 24
```
